## 🚀 Sobre o Projeto
O **CriaWeb** é uma plataforma criada com o objetivo principal de divulgar e vender os serviços de **Henrick Ferreira** como desenvolvedor freelancer. Focado em atender lojas, empresas e clientes que desejam lançar ou escalar seus sistemas na internet, com ênfase em **aplicações de médio porte**.

## 🛠 O que eu desenvolvo (Escopo)
Minha atuação é estritamente voltada para **Aplicações Web (Fullstack)**. Isso inclui:
- ✅ Desenvolvimento completo de Front-end e Back-end.
- ✅ Implementação de camadas extras sob demanda (sistemas de logs estruturados, métricas, painéis administrativos, etc).
- ✅ Integração com APIs, serviços terceirizados e infraestrutura (Deploy).

**O que eu NÃO desenvolvo:**
- ❌ Aplicativos nativos para Desktop.
- ❌ Aplicativos nativos para Mobile (iOS/Android).
- ❌ Software para sistemas embarcados.

## 💰 Modelo de Negócio e Orçamentos
Atualmente, opero com um modelo de **orçamento personalizado**, onde o valor do projeto é definido em negociação direta comigo. Alinhamos de comum acordo:
- O valor principal de desenvolvimento do software.
- Custos secundários envolvendo infraestrutura, hospedagem e serviços externos (ex: APIs e Cloud).
*Nota: Futuramente a plataforma apresentará planos fechados e tabelados para agilizar propostas.*

## 💻 Tecnologias Utilizadas
Este site foi construído utilizando tecnologias modernas de desenvolvimento web:
- **React & Vite** - Para uma interface rápida, otimizada e reativa.
- **TanStack Router** - Para um roteamento eficiente e escalável.
- **Tailwind CSS** - Estilização utilitária elegante.
- **Componentes UI** - Biblioteca própria de componentes acessíveis, dinâmicos e bonitos.
